Group5 FPS

8-week Unity FPS. Lead programmer: sprint assignment, code review, QA, and Git merges to a shipped MVP.

GitHub

Overview

Eight-person student team (two leads, plus designers and programmers) built a playable Unity FPS in eight weeks. After a shared design and technical document, we ran weekly sprints, professor reviews every two weeks, and shipped a minimum viable product.

Contributions

  • Assigned weekly programming tasks to three programmers by strength, and owned a gameplay/systems task myself.
  • Ran version control: reviewed branches, merged to main, and resolved Git issues at the end of each sprint.
  • Tested each programmer’s work the night before standup, wrote repro notes, then reviewed bugs with them one-on-one.
  • Coordinated with the lead designer on tools, mechanics, and whether the team was on track for professor deliverables and MVP.

Challenges

Keeping three programmers unblocked while still writing my own code, catching bugs before merge, and staying aligned with design without turning every Discord ping into a meeting.

Lessons Learned

Private testing plus short 1:1s caught more issues than group review alone. Clear sprint ownership and a single merge pass at the end of the week kept main stable enough to hit MVP.
