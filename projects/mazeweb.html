MazeWeb

Unity WebGL maze game wrapped in a custom browser shell with integrated audio.

Overview

MazeWeb embeds a Unity WebGL maze build inside a custom web shell — complete with UI chrome, video intro, and JavaScript audio/interaction layers — so the game runs as a full browser experience rather than a bare canvas.
